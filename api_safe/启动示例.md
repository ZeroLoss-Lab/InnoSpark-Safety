## 🚀 启动命令示例

### 1. 完整功能启动
```bash
python start_enhanced_api.py
```
- ✅ 启动前拦截 (8001端口)
- ✅ 启动后拦截 (8002端口)  
- ✅ 启动主API (8003端口)
- ✅ 启用RAG功能
- ❌ 禁用API文档
- 🔑 使用你的api_keys.json文件

### 2. 禁用拦截功能
```bash
python start_enhanced_api.py --no-front --no-post
```
- ❌ 禁用前拦截
- ❌ 禁用后拦截
- ✅ 启动主API (8003端口)
- ✅ 启用RAG功能

### 3. 仅RAG功能
```bash
python start_enhanced_api.py --no-front --no-post --enable-docs
```
- ❌ 禁用所有拦截
- ✅ 启用RAG功能
- ✅ 启用API文档（需要密钥认证）

### 4. 自定义端口
```bash
python start_enhanced_api.py --port 9000
```
- 主API服务运行在9000端口

### 5. 生产环境配置
```bash
python start_enhanced_api.py --port 80 --no-rag
```
- 80端口运行
- 禁用RAG功能（提高性能）

## 🔧 密钥管理

### 禁用某个密钥
编辑 `api_keys.json`，将对应密钥的 `enabled` 设置为 `false`：

```json
{
  "sk-your-api-key-3": {
    "created_at": "2024-01-01T00:00:00",
    "last_used": "2025-07-21T11:00:49.733164",
    "usage_count": 2,
    "description": "测试API key",
    "enabled": false
  }
}
```

### 添加新密钥
在 `api_keys.json` 中添加新的密钥条目：

```json
{
  "sk-new-api-key-001": {
    "created_at": "2025-01-01T00:00:00",
    "last_used": null,
    "usage_count": 0,
    "description": "新用户API key",
    "enabled": true
  }
}
```
