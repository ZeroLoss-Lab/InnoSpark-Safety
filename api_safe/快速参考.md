# 主API启动快速参考

## 🚀 基本命令

```bash
# 默认启动（推荐）
python start_main_api.py

# 查看所有参数
python start_main_api.py --help
```

## 🎛️ 功能开关

| 功能 | 启用（默认） | 禁用 |
|------|-------------|------|
| 前拦截 | `python start_main_api.py` | `--no-front` |
| 后拦截 | `python start_main_api.py` | `--no-post` |
| RAG系统 | `python start_main_api.py` | `--no-rag` |
| API文档 | `--enable-docs` | 默认禁用 |

## 🔗 服务地址配置

```bash
--front-url http://IP:PORT/intercept    # 前拦截API地址
--post-url http://IP:PORT/intercept     # 后拦截API地址  
--rag-url http://IP:PORT/retrieve       # RAG服务地址
--vllm http://IP:PORT                   # vLLM服务地址
```

## ⚙️ BERT阈值配置

```bash
--bert-front-high 0.97    # 前拦截高阈值（≥直接拦截）
--bert-front-low 0.00002  # 前拦截低阈值（>进入中间判断）
--bert-post 0.5           # 后拦截阈值（≥拦截输出）
```

## 📄 关键词文件路径配置

```bash
--high-sensitive-path PATH         # 高敏感关键词文件路径  
--low-sensitive-path PATH          # 低敏感关键词文件路径
```

## 🔑 API密钥配置

```bash
--api-keys api_keys.json     # 多密钥文件
--single-key sk-your-key     # 单个密钥
```

## 📋 常用组合

### 生产环境
```bash
python start_main_api.py --port 443 --api-keys prod_keys.json
```

### 开发环境  
```bash
python start_main_api.py --port 8080 --enable-docs --single-key dev-key
```

### 仅语言模型
```bash
python start_main_api.py --no-front --no-post --no-rag
```

### 高安全模式
```bash
python start_main_api.py --bert-front-high 0.99 --bert-post 0.3
```

### 分布式部署
```bash
python start_main_api.py \
  --front-url http://server1:8001/intercept \
  --post-url http://server2:8002/intercept \
  --rag-url http://server3:9000/retrieve
```

## 🏗️ 启动顺序

1. **启动外部服务**：Safe API + RAG + vLLM
2. **启动主API**：`python start_main_api.py [参数]`

## 🔧 默认配置

- 主API端口：8003
- 前拦截：http://localhost:8001/intercept
- 后拦截：http://localhost:8002/intercept  
- RAG服务：http://localhost:8000/retrieve
- vLLM服务：http://localhost:8000
- API密钥文件：api_keys.json
- API文档：禁用（安全）
